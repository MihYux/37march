# ReHoYo 角色同行 PRD 验收矩阵

本文档对应 `ReHoYo_角色同行计划_PRD_v1.0.md` 的 36 条验收标准。机器可读来源为 [`../shared/prd-acceptance.json`](../shared/prd-acceptance.json)，`npm run audit:acceptance` 会检查编号、领域、状态和证据文件。

状态口径：

- “通过”表示当前本地原型已有实现，并至少有一项自动化测试证据；
- “正式发布阻断”不等于 PRD 原型功能失败，另见[发布检查表](./RELEASE_CHECKLIST.md)；
- 测试环境使用显式模拟玩家和本地沙盒，不代表真实游戏账号或真实发行系统。

## 自动化范围

`npm run test` 当前包含：

- 角色 Profile、领域规则、记忆、消息、联系策略和发行审核单元测试；
- DeepSeek、CosyVoice、安全门禁、预算熔断和安全存储测试；
- Electron preload 与主进程 IPC 通道契约测试；
- 窗口拖动、位置恢复、多屏约束、吸附和桌宠状态测试；
- Day 1、Day 14、Day 42 的三分钟完整演示测试；
- 记忆引用撤销后不再进入后续发行内容的回归测试；
- 核心前景色/背景色的 WCAG AA 对比度计算测试。

人工界面检查在默认 `430 × 660` 窗口进行，覆盖主要面板滚动、无横向溢出、关闭按钮、`Esc`、Tab 焦点、模态语义和控制台错误。

## 与正式发布门禁的区别

以下事项仍阻止正式公开或商业发行，但不影响从源码运行本地原型：

1. 当前角色 PNG 的明确使用与再分发证据尚未归档；
2. macOS Developer ID 签名和公证尚未配置；
3. Windows 与 Linux 尚未在对应原生系统完成全链路验证；
4. 自动更新、签名发布源和回滚尚未实现。

运行 `npm run audit:release:strict` 会因为上述事项返回失败，这是有意的安全门禁。
