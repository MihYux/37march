# 隐私说明（本地原型）

本说明适用于 ReHoYo 三月七桌宠本地 MVP。它不是对真实游戏账号或线上发行系统的说明。

## 默认行为

- 不配置 API Key 时，聊天使用本地规则回复，不向第三方发送内容。
- CosyVoice 默认关闭；确认声音使用授权并主动启用后才可调用。
- 不读取真实游戏账号、支付记录、通讯录、桌面内容、麦克风、精确位置或浏览器历史。
- 自由聊天原文只保存在当前 React 内存。系统可能在玩家明确表达偏好时生成一条简短记忆候选，但只有玩家确认后才会保存；敏感类别不会形成候选。
- 共同相册、通信、授权、发行沙盒和执行日志保存在 Electron `userData` 目录。

机器可读的数据清单见
[`shared/privacy-manifest.json`](../shared/privacy-manifest.json)。

## 第三方数据流

### DeepSeek

启用在线聊天后，会发送角色系统提示、最近必要对话上下文、当前消息，以及最多三条已确认且允许复用的相关记忆摘要。发行控制台使用有限生成时，只发送当前任务的已锁定且已解禁事实、最多六条已审核知识片段和角色规则；不会发送原始方案文件、未审核或未解禁片段、其他活动内容、共同相册或 DashScope API Key。

### DashScope CosyVoice

启用语音后，会发送当前待朗读文本、音色 ID、语速、语言和表达指令。不会发送完整聊天历史、共同相册、本地声音样本或 DeepSeek API Key。

第三方服务可能按各自条款处理请求。正式发行前必须再次核对其最新隐私条款、地区可用性与数据保留规则。

## 本地文件与保护

- `companion-data.json`：关系、授权、相册、通信、发行任务与执行日志。
- `ai-settings.json`：模型偏好和可选加密 Key。
- `tts-settings.json`：语音偏好、授权确认和可选加密 Key。
- `service-usage.json`：当天请求数、字符数和熔断状态，不保存正文。
- `window-state.json`：窗口位置、尺寸、置顶和吸附。

业务数据与 API Key 分文件保存。系统安全存储可用时使用 Electron `safeStorage`；不可用时新 Key 只保存在当前进程。macOS 也可从系统钥匙串读取 DashScope Key。

## 玩家控制

- 在“同行”中修改主动联系、内容、频率、勿扰、个性化与记忆授权。
- 暂停或退出同行，立即停止主动联系。
- 查看、导出、关闭引用、删除单条或清空共同记忆；发行引用需要单独授权，撤销后立即停止进入后续上下文。
- “导出全部”导出本地同行业务数据，不包含 API Key、音频缓存或自由聊天。
- “删除关系数据”清空相册、通信、关系、任务和日志并恢复未授权初始状态。
- 在模型与语音设置中清除保存的 Key；环境变量和系统钥匙串需在对应系统入口删除。

## 数据保留

本地业务数据保留到玩家删除关系数据或清除应用数据。调用预算按 UTC 日期跨日自动重置。音频仅在内存播放，播放结束后释放。应用不提供云端同步。
