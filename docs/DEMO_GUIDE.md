# 三分钟演示指南

本演示使用完全本地的模拟玩家、模拟发行任务和独立 Demo 时钟，不读取真实游戏账号，不修改电脑系统时间，也不会向外部分发内容。DeepSeek 和 CosyVoice 都不是演示必需项。

## 演示前准备

```bash
npm install
npm run check
npm start
```

应用启动后：

1. 在桌宠右侧快捷入口打开“演示”；
2. 点击“重置 Demo”，确认当前案例为“日本剧情玩家”；
3. 确认页面显示“模拟数据”和 Day 0；
4. 如需完全离线演示，不配置 DeepSeek 和 CosyVoice 即可。

## 建议讲解路线

### 0:00–0:30：关系与共同记忆

1. 打开“相册”；
2. 展示玩家确认的共同选择或旅行照片；
3. 关闭某条记忆的“允许未来引用”，说明后续内容生成不能使用它；
4. 恢复开关，以便继续演示自然的版本衔接。

预期结果：相册明确显示模拟数据、用户确认状态和引用开关，普通聊天不会自动进入长期记忆。

### 0:30–1:00：Day 1 的低打扰预热

1. 回到“演示”并推进到 Day 1；
2. 打开“发行”，找到自动检查通过但等待人工审核的预热消息；
3. 展开来源，展示 Skill 版本、固定事实、规则和记忆引用；
4. 人工批准后再投递；
5. 打开“通信”，确认消息此时才对玩家可见。

预期结果：未批准内容不会进入玩家通信中心，投递内容只有一个产品内行动目标。

### 1:00–1:40：Day 14 的版本上线

1. 推进到 Day 14；
2. 观察关系阶段从新认识发展为同行；
3. 在“发行”中审核上线消息；
4. 确认活动名称、时间、奖励声明和 `product://` 目标来自锁定事实；
5. 投递后在“通信”中点击喜欢或收藏；
6. 点击版本行动，打开本地模拟发行页。

预期结果：版本内容从获准的共同经历自然切入，不编造外部链接或真实游戏事实。

### 1:40–2:30：Day 42 与玩家负反馈

1. 推进到 Day 42；
2. 审核并投递持续期消息；
3. 在“通信”中选择“不感兴趣”；
4. 返回“发行”，确认任务立即暂停，活动关联已移除；
5. 打开“同行”，确认日常内容授权仍保留。

预期结果：负反馈停止后续活动触达，但不删除共同记忆，也不破坏日常陪伴。

### 2:30–3:00：安全证据与完整重置

1. 在“演示”触发“不安全外链 / 付费诱导”风险动作；
2. 查看执行日志和自动检查失败证据；
3. 确认风险消息没有 `sentAt`，不会出现在玩家通信中心；
4. 点击“重置 Demo”；
5. 确认回到日本剧情玩家 Day 0，数据与默认案例一致。

预期结果：安全失败不能靠人工操作绕过；Demo 重置不删除独立保存的模型或语音设置。

## 可选分支

- 中国活跃玩家：更高的周联系上限，可展示不同联系强度；
- 北美强度玩家：长期记忆关闭，并可在相同时刻因当地勿扰而保持沉默；
- 连续忽略两次：触发七天安静期；
- 退订版本内容：停止版本任务并关闭对应内容类型；
- 暂停同行：所有主动联系保持沉默，玩家主动操作仍可用。

## 演示失败时

- 没看到消息：先检查消息是否已完成人工审核和投递；
- 事件被抑制：在执行日志查看 `quiet_hours`、`weekly_limit`、`content_type_disabled` 等原因；
- 面板内容不是默认状态：点击“重置 Demo”；
- 在线模型或语音失败：继续使用本地回复和文字演示，核心流程不依赖第三方；
- 窗口无法点击：从系统托盘选择“恢复交互”；
- 更完整的排查见[故障排查](./TROUBLESHOOTING.md)。
