# 故障排查

## 应用无法启动

1. 确认 Node.js 20 或更高版本；
2. 删除并重新安装依赖前，先保存自己的未提交改动；
3. 运行 `npm run build` 查看 TypeScript 或资源路径错误；
4. 运行 `npm start`，不要只打开 `dist/index.html`；
5. macOS 未签名目录仅用于本机开发，正式分发需要签名和公证。

## 桌宠无法点击

点击穿透只有在系统托盘成功创建时才能开启。请在托盘菜单选择“恢复交互”。应用重启时也会强制恢复可点击，不会持久化穿透状态。

如果托盘本身不可用，应用会拒绝进入点击穿透。

## 窗口跑到屏幕外

显示器断开或工作区变化时，窗口会重新约束到可见区域。若仍异常：

1. 从托盘选择显示窗口；
2. 拖动到任意屏幕边缘触发重新吸附；
3. 关闭应用后备份并移走用户数据目录中的 `window-state.json`；
4. 重启会使用主屏右下角安全默认位置。

## 对话框无法关闭

- 点击面板右上角关闭按钮；
- 按 `Esc` 关闭当前浮层；
- Tab 和 Shift+Tab 只会在当前模态面板内循环；
- 若界面无响应，可从托盘隐藏并重新显示；
- 若仍能复现，请记录打开顺序、当前面板、平台和控制台错误。

## DeepSeek 不工作

- 未保存 Key：打开模型设置重新保存；
- 环境变量覆盖：`DEEPSEEK_API_KEY` 优先于应用设置；
- 模型调用失败：应用自动回退到本地三月七回复；
- 达到日预算：等待 UTC 日期切换，或在设置中查看使用状态；
- 连续失败熔断：等待五分钟后重试；
- 安全门禁拦截：界面会返回本地角色边界回复，请勿尝试提取系统提示或提交越界内容。

Key 不会通过公共设置接口回显。安全存储不可用时，新 Key 只保留到本次应用退出。

## CosyVoice 没有声音

依次检查：

1. 已确认声音样本与复刻音色授权；
2. 已保存 DashScope API Key；
3. 语音输出已开启；
4. `voiceId` 对当前业务空间和 Key 可访问；
5. 音量不是 0；
6. 点击单条消息旁的喇叭进行手动测试；
7. 设置面板的服务预算未耗尽；
8. 目标服务没有进入五分钟熔断。

自动朗读默认关闭。文字回复和本地互动不依赖 TTS。

## Demo 没有生成消息

检查执行日志中的抑制原因：

- `quiet_hours`：处于玩家当地勿扰时段；
- `weekly_limit`：达到每周主动联系上限；
- `content_type_disabled`：玩家关闭了对应内容类型；
- `quiet_period`：连续忽略后处于安静期；
- `reduced_frequency`：玩家要求降低此类频率；
- `duplicate_template`：七天内已使用相同模板；
- `automatic_check_failed`：事实、人设、外链或安全检查失败。

消息还需要人工审核和明确投递，才会进入玩家通信中心。

## 数据损坏或需要重置

- Demo 数据：在 Demo 控制中心点击“重置 Demo”；
- 关系数据：在同行设置选择退出或删除全部关系数据；
- 记忆：在共同相册单条删除或清空；
- 完整业务数据：删除前先使用“导出同行数据”；
- 损坏 JSON：Store 会保留 `.invalid-*` 备份并回退到安全默认数据。

删除关系数据不会删除独立保存的模型和语音 API Key。不要把用户数据目录上传到公开 Issue。

## 打包失败

- 先执行 `npm run check`；
- GitHub 或 Electron 下载网络失败时可在网络恢复后重试 `npm run package`；
- 当前生成未签名应用目录，签名警告是原型阶段预期结果；
- Windows 和 Linux 目标虽然已配置，但必须在对应系统原生验证；
- 正式发布前运行 `npm run audit:release:strict`，不要忽略其阻断结果。
