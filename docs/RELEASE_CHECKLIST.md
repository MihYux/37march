# 发布检查表

本项目当前是已通过 PRD 原型验收的源码原型，不是可正式公开分发的签名产品。任何发布决定都必须同时满足功能、隐私、安全、资产权利和平台门禁。

## 自动门禁

```bash
npm ci
npm run check
npm run package
npm run audit:release:strict
```

| 门禁 | 当前状态 | 说明 |
| --- | --- | --- |
| 36 条 PRD 原型验收 | 通过 | `npm run audit:acceptance` |
| 前端与主进程测试 | 通过 | 包含 IPC 和三分钟演示 |
| TypeScript 与 Vite 生产构建 | 通过 | `npm run build` |
| 密钥、临时链接和受限素材扫描 | 通过 | `npm run audit:release` |
| macOS 未签名应用目录 | 已本机验证 | 仅限开发与内部验收 |
| 角色视觉再分发证据 | 阻断 | 正式发布前必须归档 |
| macOS 签名与公证 | 阻断 | 需要 Developer ID |
| Windows/Linux 原生验证 | 阻断 | 需要对应系统实机或 CI |
| 自动更新与回滚 | 阻断 | 需要签名更新源和回滚演练 |

因此，`npm run audit:release:strict` 当前应返回失败。若它意外通过，先检查 `shared/release-risk-register.json` 是否被错误修改。

## 资产与许可

- [ ] 当前角色 PNG 的来源、权利人、允许用途、再分发范围和署名要求已归档；
- [ ] 原始 Live2D、受限音频、RAR、临时 OSS 地址和 API Key 不在 Git 历史或安装包；
- [ ] March7th.Skill 的 MIT notice 和固定上游提交仍在安装包；
- [ ] 字体、图标和所有 npm 依赖的许可已复核；
- [ ] 声音样本与复刻音色的授权证据保存在仓库外的受限位置；
- [ ] 产品内有关闭语音、撤销声音授权和下架音色的路径；
- [ ] 非官方同人声明清晰可见。

## 隐私与安全

- [ ] 首次进入披露模拟数据、DeepSeek 和 DashScope 数据流；
- [ ] API Key 不出现在渲染进程、导出、日志、崩溃报告或安装包；
- [ ] 完整数据导出、记忆撤销、暂停、退出和删除均已实测；
- [ ] 输入/输出内容安全、发行双层审核和联系策略测试通过；
- [ ] `companion-data.json`、设置、预算和窗口状态文件权限符合平台预期；
- [ ] 第三方服务不可用、超时、余额不足和熔断时本地流程仍可使用；
- [ ] 隐私说明、保留周期、删除方式和安全报告渠道已由负责人复核。

## 平台验证

每个平台至少验证：

- 安装、首次启动、升级、降级与卸载；
- 透明窗口、拖动、多屏、缩放、吸附、全屏空间和置顶；
- 托盘、右键菜单、隐藏到托盘和点击穿透恢复；
- `safeStorage` 或平台钥匙串；
- DeepSeek、CosyVoice、取消、离线回退和防火墙场景；
- 相册、通信、发行、Demo、导出、删除和重启恢复；
- 键盘 Tab/Shift+Tab、`Esc`、焦点可见、屏幕阅读器名称和 200% 缩放；
- 崩溃后数据完整性与损坏文件备份；
- 安装包签名、校验、公证/信誉提示和发布源。

## 发布与回滚

- [ ] 版本号、变更记录和 Git tag 一致；
- [ ] 发布提交已通过干净环境的 `npm ci && npm run check`；
- [ ] 构建产物来自受控 CI，保存校验值和构建日志；
- [ ] 更新源强制 HTTPS，并验证签名后再安装；
- [ ] 灰度、暂停发布、紧急下架和回滚负责人明确；
- [ ] 数据 schema 的向前迁移与回滚行为已演练；
- [ ] 旧版本遇到新数据时不会静默损坏；
- [ ] 语音或角色资产授权被撤销时可以独立关闭而不阻塞文字版。

## 发布结论

只有当严格审计通过、所有高风险阻断关闭、目标平台实测完成后，才能把状态从“源码原型”改为“可正式分发”。在此之前可以继续本地开发、内部演示和经授权的受控验收。
